# TKA後に膝が曲がらないとき、まず何を疑う？｜「無理に曲げる」から脱却する屈曲制限の評価とアプローチの基本

「毎日しっかり曲げているのに、なかなか90°を超えない」
「患者さんが痛がって力を入れてしまい、リハビリが苦行のようになっている」

人工膝関節全置換術（TKA：Total Knee Arthroplasty）後のリハビリで、膝関節の屈曲可動域（ROM：Range of Motion）が伸び悩む場面は、新人〜中堅の理学療法士が特につまずきやすいポイントです。

つい「もっとしっかり曲げないと固まってしまう」と焦り、痛みを我慢させながら他動的に曲げてしまいたくなることもあります。しかし、最新のガイドラインや臨床研究を踏まえると、**「とりあえず強く曲げる」アプローチは、かえって炎症や防御性収縮を助長し、回復を遠ざけるおそれ**があることが指摘されています[8, 9]。

この記事では、2026年改訂版の米国理学療法士協会（APTA）診療ガイドラインや国内外の一次文献をもとに、**TKA後の屈曲可動域制限を評価・解釈するための基本の軸と、明日の臨床から実践できるアプローチの考え方**を整理します。

## 1. まず整理したい：その屈曲制限は「PTの介入で変えられるもの」か？

TKA後に膝が曲がらないとき、最初に立ち止まって確認したいのは「そもそも何が動きを止めているのか」という原因の切り分けです。

TKA後の関節拘縮（いわゆる stiff TKA）は、定義によって幅があるものの**全体の4〜16%に発生する**と報告されており、単一の原因ではなく「術前・術中・術後」の複数要因が絡み合って生じます[8]。

### 術前・術中・術後の3層で原因を切り分ける

まずは、目の前の患者さんの制限因子を以下の3つの層に分けて整理してみてください。

| 要因の層 | 代表的な因子 | 理学療法での修飾可能性と臨床での活かし方 |
| :--- | :--- | :--- |
| **① 術前因子** | 術前の屈曲ROM制限、高BMI、膝手術の既往、抑うつなど[2, 6, 8] | 術後には変えられない。**「現実的な目標設定」と「ハイリスク群の早期把握」**に活かす |
| **② 術中因子** | 屈曲・伸展ギャップの不均衡、コンポーネントのサイズ不適合や回旋アライメント異常、伸筋機構（膝蓋腱など）への侵襲[8] | 徒手や運動で構造そのものは変えられない。**骨性・機械的なブロックが疑われる場合は医師へ共有**する |
| **③ 術後因子** | 疼痛管理不足、関節腫脹、運動恐怖（kinesiophobia）、不適切な運動負荷、**感染症**、特発性関節線維症、CRPS（複合性局所疼痛症候群）、異所性骨化[8, 9] | 疼痛・腫脹・軟部組織の滑走性・運動恐怖・運動負荷は**PTが積極的に介入できる領域**。一方、**感染やCRPSは最優先で除外・医師報告**する |

特に知っておきたいのが、**術前の屈曲角度は術後の屈曲角度を予測する最も強い因子の一つである**という事実です。Ritterら（2003／抄録確認）による初回TKA 3,066名（4,727膝）の後方視的研究では、術前の下肢アライメントにかかわらず、術前屈曲角度が術後屈曲角度の最強の予測因子であり、術中屈曲角度も有意に関連することが報告されています[6]。

※なお、APTAの2020年診療ガイドラインでは「術前ROMは術後ROMと正の関連があるものの、身体機能やQOLへの影響は最小限である」と整理されています[2]。術前屈曲が95°だった患者さんに対して、術後に「何としても130°まで曲げよう」と無理を重ねるのは合理的ではありません。

### 「ただの回復の遅れ」と「関節線維症（Arthrofibrosis）」の違い

術後数週間で屈曲角度が思うように伸びないとき、「関節線維症（arthrofibrosis：関節内に過剰な瘢痕・線維組織が形成されて動きが制限される状態）」を心配されることがあります。

2016年の国際専門家合意（Kalsonら／抄録および引用確認）では、術後の膝関節線維症は以下のように定義・分類されています[7, 9]。

* **定義：** コンポーネントの設置不良やサイズ不適合、感染（化膿性関節炎）、疼痛、CRPSなどの特異的原因によるものではない、**術前には存在しなかった軟部組織の線維化によるROM制限**
* **屈曲制限の重症度分類：** 軽度 90°〜100° ／ 中等度 70°〜89° ／ 重度 70°未満
* **伸展制限の重症度分類：** 軽度 5°〜10° ／ 中等度 11°〜20° ／ 重度 20°超

ここで大切なのは、**「曲がらない＝すべて関節線維症（硬いから強く曲げるしかない）」ではない**という点です。Rodríguez-Merchán（2019）のレビューでも強調されている通り、術後の拘縮で**最も見逃してはならない原因は「感染」**であり[8]、さらに疼痛や運動恐怖（術後TKA患者の24.4%に認められたとする報告あり[8]）など、軟部組織の線維化以外の要因を切り分ける姿勢が不可欠です。

## 2. 数値に振り回されないための評価の軸｜目標角度・測定誤差・時期別目安

屈曲制限を正しく評価するためには、「何度を目標にするのか」「その5°の変化は本物か」「今は焦るべき時期なのか」という3つの物差しを持っておく必要があります。

### 動作別の必要屈曲角度と「伸展0°を犠牲にしない」原則

「とりあえず90°、できれば120°」と一律に目標を置くのではなく、患者さんが自宅で必要とする生活動作から逆算して目標を共有しましょう。

Roweら（2000／抄録確認）は、**健常高齢者20名（平均年齢67歳）**を対象に電気角度計で日常生活動作中の膝屈曲角度を計測し、以下の目安を報告しています[4]。

* **平地歩行・坂道歩行：** 90°未満
* **階段昇降・椅子からの立ち座り：** 90°〜120°
* **浴槽を跨いで入浴する動作：** 約135°
* **リハビリテーションにおける妥当な目標の目安：** 約110°

※このデータは健常高齢者20名から得られたものであり、TKA術後の患者さんや日本の床生活（正座・しゃがみ込みなど）にそのまま当てはまるわけではありません[4]。あくまで「生活動作ごとの必要角度の目安」として患者さんとすり合わせる材料にしてください。

また、屈曲角度ばかりに意識が向くと見落としがちですが、**膝伸展0°の獲得・維持を犠牲にして屈曲練習を進めてはいけません**。伸展制限（屈曲拘縮）が残存すると歩行時の大腿四頭筋への負担が増し、歩容や日常機能に大きく影響するため、常に「伸展と屈曲の両立」を確認する視点が大切です。

### ゴニオメーターの測定誤差と、統一すべき測定条件

臨床で「昨日は95°だったのに、今日は90°に落ちた」と患者さんもセラピストも落ち込んでしまう場面はよくあります。しかし、その5°の差は**本当の悪化ではなく、測定誤差の範囲内**かもしれません。

Lenssenら（2007／抄録確認）は、TKA術後3日目の入院患者30名に対し、熟練した理学療法士2名が50cmのロングアームゴニオメーターを用いて膝ROMの検者間再現性を検証しました[5]。

その結果、**異なる検者が急性期TKA患者を測定する場合、8°未満の差は測定誤差と区別できない**と結論づけられています[5]。また、検者間一致度は背臥位での他動屈曲が最も低く、座位での他動屈曲（平均差2.7°、一致限界 -6.7°〜12.1°）のほうが一致度が高い傾向が示されました[5]。

※なお、術後拘縮に対する多施設RCT（Abdelら、2024）では、総可動域の**臨床的に意味のある最小変化量（MCID）として10°**が参照されています[10]。

測定値のブレを減らすため、カルテには角度だけでなく以下の4条件をセットで残すことを徹底しましょう。

1. **測定肢位：** 背臥位か、端座位か（股関節屈曲角度で二関節筋である大腿直筋の張力が変わるため）
2. **運動様式：** 自動（AROM）か、自動介助（AAROM）か、他動（PROM）か
3. **終了基準（エンドポイント）：** 「疼痛出現時」か「自制内の最大域」か
4. **検者と時間帯：** 可能な限り同一検者・同一条件（運動前後、鎮痛薬の内服タイミング）で追う

### 術後5日よりも「術後1か月」が重要な理由（日本のデータから）

「術後1週間で90°に届いていないけれど、将来曲がらなくなるのでは？」という不安に対して、日本の単施設後方視的研究（Okaら、2020）が参考になるデータを示しています[11]。

Okaら（2020）は、内側型変形性膝関節症で**術前屈曲120°以上**の初回片側TKA患者193名（平均年齢73.2歳）を対象に、術後12か月時点で屈曲120°を達成するための急性期カットオフ値を解析しました[11]。

* **術後5日時点のカットオフ値：85°**（感度0.27、特異度0.94、AUC 0.63）
  → 入院直後は疼痛・麻酔・鎮痛薬の影響が大きく、**術後5日時点の角度だけで長期予後を予測する精度は低い**。
* **術後1か月時点のカットオフ値：105°**（感度0.63、特異度0.82、AUC 0.80）
  → 術前や術後5日よりも予測精度が高く、**術後1か月までの回復推移と疼痛管理が重要**（未達成群では術後1か月時点の歩行時痛NRSが有意に高かった：4.0 ± 1.6 vs 2.3 ± 1.7、p < 0.01）。

※この研究は「術前屈曲120°以上の内側型膝OA」「単施設・同一機種」「後方視的研究」という限界があるため、術前屈曲が低い患者さんへそのまま当てはめることはできません[11]。あくまで**「術後数日の角度で悲観しすぎず、術後1か月前後の推移と痛みを丁寧に追う」**ための指標としてご活用ください。

## 3. 最新ガイドライン（APTA 2026改訂版）が示すROM介入の現在地

2026年7月に改訂された米国理学療法士協会（APTA）のTKA診療ガイドライン（Boveら、2026）は、術後のROM介入について明確な指針を示しています[1]。

| 介入手段 | APTA 2026 ガイドラインの推奨 | エビデンスの質 / 推奨の強さ | 臨床で押さえるべきポイント |
| :--- | :--- | :--- | :--- |
| **CPM（持続的他動運動装置）** | 非合併症の初回TKAには**使用しないことを推奨** | 高（High） / **強い推奨（Strong）** | ルーチン使用を支持する臨床的意義なし。離床や能動的リハの機会を減らす懸念[1, 3] |
| **術後早期の装具・スプリント** | ROM改善目的での**ルーチン使用は推奨しない** | 中等度（Moderate） / 中等度（Moderate） | 移動の妨げやコスト増。ただし**重度拘縮・関節線維症は除外対象**であり個別検討[1, 9] |
| **他動・自動介助・自動ROM運動** | 回復最適化のため**実施を推奨** | 中等度（Moderate） / 中等度（Moderate） | 自動・他動・PNFの間で単一の最強手法は証明されておらず、耐容性に合わせて組み合わせる[1] |
| **徒手療法・補助機器の併用** | 運動療法と併用して**使用してもよい** | 中等度（Moderate） / 弱い推奨（Weak） | スライドボード、エルゴメータ、関節・軟部組織モビライゼーション等は快適性や主体性向上の選択肢[1] |
| **クライオセラピー（冷却療法）** | 術後早期の疼痛管理として**推奨** | 中等度（Moderate） / 中等度（Moderate） | 疼痛軽減によりROM運動を行いやすい環境をつくる[1] |

### CPMが「強い非推奨」となった背景

Harveyら（2014／抄録確認）のコクランレビュー（24件のRCT、計1,445名）では、CPMによる短期的な自動膝屈曲ROMの増加は**平均わずか2°（95% CI：0°〜5°）**にとどまり、疼痛・機能・QOLにも臨床的に意味のある効果は認められませんでした[3]。

※同レビューで示唆されたMUA（麻酔下徒手授動術）リスク低下のエビデンスの質も「非常に低い（very low）」と評価されています[3]。

APTA 2026改訂版では、CPMの不使用が2020年版の「中等度推奨」から**「強い推奨（Strong）」へ格上げ**されました[1, 2]。機械任せに受動的に動かす時間を増やすよりも、患者さん自身が自動・自動介助で動かす機会と早期離床・歩行練習を優先することが国際標準です[1]。

### 「痛いのに強く曲げる」が逆効果になりうる理由

Rauziら（2022）は、早期関節線維症に対する多面的理学療法プロトコルの考察の中で、**過度に強いROM運動や徒手療法は、疼痛と炎症・線維化反応（fibrotic/inflammatory response）を増幅させ、結果として患者さんの「自分で膝を動かそうとする意欲」を低下させる**と指摘しています[9]。

また、徒手療法の作用機序についても、物理的な力で瘢痕を引きちぎるのではなく、**神経生理学的な疼痛変調（痛みを和らげて動かしやすくする効果）を介した関与が大きい**という現代的な理解が示されています[9]。

## 4. 角度だけで決めない！臨床で必ず確認したい「4つの基本評価」

「屈曲90°で止まる」という結果だけを見て介入を決めるのではなく、必ず以下の4つをセットで確認して制限因子を絞り込みましょう。

1. **疼痛・突っ張り感の「部位」**
   * 膝全体の張り感 → **関節内血腫・腫脹**による内圧上昇を疑う
   * 膝前面（膝蓋骨周囲〜大腿遠位）の突っ張り → **膝蓋上嚢・大腿四頭筋伸筋機構・膝蓋骨周囲の滑走低下**を疑う
   * 膝後面の詰まり感・挟み込み感 → **後方軟部組織の挟み込み、または後方骨棘・ギャップなどの機械的因子**を疑う
2. **エンドフィール（最終域感）とAROM/PROMの差**
   * 水袋のように弾力的に止まる → 腫脹・関節水腫優位
   * 硬くカツンと止まる → 構造的・機械的ブロックの可能性（無理に押し込まず医師確認）
   * AROMとPROMの乖離が大きく、触れる前から大腿四頭筋に力が入る → **運動恐怖・防御性収縮**優位
3. **股関節肢位による変化（二関節筋の切り分け）**
   * 股関節を伸展させた肢位で膝屈曲が明らかに減り、股関節屈曲位では曲がる場合、関節内ではなく**大腿直筋（二関節筋）の柔軟性低下**が強く関与しています。
4. **膝蓋骨の「尾側滑走」と周径・熱感**
   * 膝を曲げる際、膝蓋骨は大腿骨の滑車溝に沿って**遠位（尾側）へ滑走**します。大腿四頭筋を完全に脱力させた伸展位で健側と比べ、膝蓋骨の尾側滑走が低下していないか、また膝蓋骨上縁の周径増大や熱感がないかを確認します。

## 5. 基本アプローチの3原則と「術後6〜12週の分岐点」

評価で制限因子の見当がついたら、以下の3つの原則でアプローチを組み立てます。

> **[図解2 挿入箇所：`diagrams/tka_flexion_diagram_2.png`]**
> *図2：TKA後 屈曲制限の臨床判断フロー（評価・低強度高頻度アプローチ・6〜12週の分岐点）*

### 原則①：「強く1回」より「痛めず低強度・高頻度」

Rauziら（2022）は、術後6週で屈曲100°未満の早期関節線維症10名に対し、**痛みを悪化させない徒手療法＋「1日5回以上（可能なら毎時間）」の自動介助ROM運動＋軽度伸張感（10段階中2〜3）での静的漸増スプリント**を組み合わせた4週間のプログラムを実施し、10名中7名（70%）が110°以上を達成してMUAを回避したと報告しています[9]。

※この研究は `n = 10` のパイロット・実行可能性試験（後方視的MUA群31名との非ランダム化比較）であり、有効性を確定するには今後の大規模RCTが必要です[9]。それでも、臨床では以下の考え方が非常に実用的です。

* リハビリ室の20〜40分で一気に角度を稼ごうとしない
* 冷却療法や鎮痛薬の内服タイミングを活用し、痛みを抑えた環境をつくる[1]
* 病棟や自宅で**1日5回以上、痛みを悪化させない範囲（軽い伸び感2〜3/10）でこまめに自動介助屈曲**（ヒールスライド、座位での健側足介助屈曲、軽負荷エルゴメータなど）を反復する[1, 9]

### 原則②：その場の角度ではなく「翌日の反応」で負荷を見直す

介入が適切だったかどうかは、24時間以内の反応で判断します。

* **適正負荷：** 翌日までに痛み・腫脹が悪化せず、角度が維持〜改善している
* **過負荷のサイン：** 翌日まで安静時痛・夜間痛が残る、周径増大や熱感の悪化、屈曲角度が測定誤差を超えて後退（8°〜10°以上）する → **強度を一段階下げて冷却・腫脹管理へ戻す**

### 原則③：レッドフラッグの除外と「術後6〜12週の医師連携」

理学療法士だけで抱え込まず、医学的介入のタイミングを逃さないことも重要な専門性です。

* **最優先で医師報告すべき徴候（Red Flags）：** 創部の発赤・熱感・腫脹増悪、排膿、発熱、安静時痛・夜間痛増悪などの**感染徴候**、刺激に見合わない激痛や皮膚色調変化などの**CRPS徴候**、硬い機械的ブロック感[8]。
* **術後6〜12週のMUA分岐点：** 感染や明らかなインプラント異常が除外されたうえで、**術後6〜12週時点で屈曲90°未満が遷延する、あるいは改善が停滞している場合**は、主治医と **MUA（麻酔下徒手授動術）** などの適応を協議する重要な時期です[8, 9, 10]。

実際、Abdelら（2024）による15施設・124名を対象とした多施設RCT（術後4〜12週でROM 90°未満のstiff TKA患者対象）では、MUA＋理学療法により**MUA直後に平均46°（術前72°→118°）、6週後に+28°、1年後に+37°の持続的なROM改善**が示されています[10]。また、12週を超えて線維が成熟するとMUAの効果低下や骨折リスクの上昇が懸念されるため[8]、**遅くとも術後8〜10週頃までに同条件のROM推移・疼痛・局所所見を整理して主治医へ共有する**ことが患者さんの長期予後を守ります。

## まとめ：明日の臨床で使えるチェックリスト

* [ ] 術前ROM・術中屈曲角度・既往手術・BMIを確認し、現実的なゴールを共有したか[6, 8]
* [ ] 測定肢位・AROM/PROM・終了基準を統一し、**検者間8°未満の差を誤差として冷静に見ているか**[5]
* [ ] 屈曲だけでなく、**膝伸展0°の維持**を毎回確認しているか
* [ ] 疼痛部位・エンドフィール・股関節肢位差・膝蓋骨尾側滑走の4点から制限因子を整理したか
* [ ] CPM任せや強い他動屈曲を避け、**冷却＋低強度（2〜3/10）・高頻度（1日5回以上）の自動介助運動**を設計したか[1, 9]
* [ ] 翌日の腫脹・疼痛反応を確認し、**感染等のRed Flagsや術後6〜12週の停滞**を適時医師へ共有しているか[8, 10]
